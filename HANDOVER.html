Technical Handover: Claypot Indian Bar & Restaurant

This document contains all necessary information for the technical handover of the Claypot website.

1. Project Overview

A premium, responsive web application built with Next.js, TypeScript, and Tailwind CSS.

2. Getting Started (Local Development)

git clone https://github.com/claypotnova-cyber/claypot-website
npm install
npm run dev

3. Deployment (Vercel)

  1. Connect GitHub to Vercel.
  2. Add Environment Variables (REDIS_URL, RESEND_API_KEY).
  3. Deploy from main branch.

4. How to Make Changes

  • Menu: Edit lib/data/menu.ts
  • Promotions: Edit lib/data/promotions.ts
  • Announcements: Edit components/AnnouncementBar.tsx
